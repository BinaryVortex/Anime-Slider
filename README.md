# Anime Slider

A clean, responsive anime-themed image slider built with plain HTML, CSS and JavaScript.

![Demo Screenshot](./Screenshot%202024-08-15%20133609.png)

Description
-----------
This repository contains a simple, lightweight anime slider that showcases images with smooth transitions and navigation controls. It's built using only HTML, CSS and vanilla JavaScript — no frameworks or build tools required.

Features
--------
- Smooth slide transitions and animations
- Previous/Next controls
- Responsive layout that works on desktop and mobile
- Easy to customize and extend

Usage
-----
1. Clone or download the repository.
2. Open `index.html` in your browser.

Customization
-------------
- Replace the images in the `images/` directory (or update the markup in `index.html`) to use your own pictures.
- Edit `style.css` to change colors, spacing, and animation timing.
- The slider behavior is implemented in `index.html` with a small script — you can move it to a separate JS file if preferred.

Files
-----
- `index.html` — markup and minimal JavaScript for the slider
- `style.css` — styles and animations
- `images/` — (optional) folder for gallery images
- `Screenshot 2024-08-15 133609.png` — demo screenshot used above

Languages
---------
- CSS (~56%)
- HTML (~44%)
